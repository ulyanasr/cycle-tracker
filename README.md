# Трекер цикла

Личный PWA-трекер менструального цикла для iPhone. Без регистрации и сервера: все данные хранятся только на телефоне.

**Адрес:** https://ulyanasr.github.io/cycle-tracker/

## Как установить на iPhone

1. Открой адрес выше **в Safari**: в других браузерах на iPhone установка не работает.
2. Нажми «Поделиться» (квадрат со стрелкой вверх) внизу экрана.
3. Пролистай меню и выбери **«На экран „Домой“»**, затем «Добавить».
4. Открывай приложение с иконки на экране «Домой»: оно запустится без адресной строки и будет работать без интернета.

> Важно: отмечай дни в приложении с экрана «Домой», а не во вкладке Safari. У них разные хранилища, и у установленного приложения данные надёжнее защищены от автоочистки.

## Бэкап

Данные живут только на этом iPhone. Если удалить приложение, они удалятся вместе с ним.

- **Сохранить:** меню ☰ → «Экспорт в Файлы» → «Сохранить в Файлы» → iCloud Drive. Файл появится и на Mac, в Finder → iCloud Drive.
- **Восстановить:** меню ☰ → «Импорт из файла» (или «У меня есть бэкап» на первом экране) → выбери файл `cycle-backup-….json`.
- Каждый месяц на главной появляется напоминание «Сохрани бэкап за…».

## Обновления

Каждый пуш в `main` сам собирается и публикуется через GitHub Actions (сначала прогоняются тесты). Приложение на iPhone подхватит новую версию при следующем открытии с интернетом.

## Для разработки

```bash
npm install
npm run dev -- --host   # dev-сервер; адрес Network открывается на iPhone в той же Wi-Fi
npm test                # тесты логики (Vitest)
npm run build           # сборка в dist/
python3 scripts/make-icons.py   # перерисовать иконки
```
