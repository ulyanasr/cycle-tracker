# Задача для Claude Code: PWA-трекер менструального цикла

Собери PWA-сайт «Трекер цикла» для личного использования на iPhone. Ниже всё, что согласовано: функции, логика расчётов, экраны, дизайн, техника и порядок работы. Если что-то в спецификации противоречит само себе или неясно — спроси меня, прежде чем решать самостоятельно.

---

## 0. Как работать (важно)

Я хочу видеть результат в реальном времени, по мере сборки.

1. Сначала создай проект и сразу запусти dev-сервер: `npm run dev -- --host`. Напиши мне адрес для Mac (localhost) и адрес по IP в локальной сети, чтобы я открыла его на iPhone в той же Wi-Fi.
2. Работай этапами (см. раздел 9). После каждого этапа:
   - коротко напиши, что сделано и что посмотреть;
   - сделай git-коммит с понятным сообщением;
   - дождись моего «ок» или правок, и только потом переходи к следующему этапу.
3. Логику расчётов (раздел 4) покрой unit-тестами на Vitest. Я QA и буду проверять граничные случаи.
4. Не добавляй ничего, чего нет в спецификации (аналитику, аккаунты, сервер, тёмную тему). Хочешь предложить улучшение — сначала спроси.

## 1. Что это и для кого

- Личный трекер цикла для одного человека, только iPhone (Safari, установка на экран «Домой»).
- Язык интерфейса: русский.
- Тема только светлая, тёмная не нужна.
- Без регистрации, без сервера, без платных сервисов.
- Данные хранятся только на устройстве.

## 2. Техника

- **Стек:** Vite + React + TypeScript.
- **PWA:** `vite-plugin-pwa`. Офлайн-работа, манифест, иконки, `display: standalone`.
- **Хранение:** IndexedDB через Dexie. При старте вызывай `navigator.storage.persist()`.
- **Даты:** date-fns с локалью `ru`. Все даты хранить как строки `YYYY-MM-DD` в локальном времени, без часовых поясов.
- **Шрифт:** Onest (через `@fontsource/onest`, веса 400–800), чтобы работал офлайн.
- **Под iOS:**
  - `apple-touch-icon`;
  - `apple-mobile-web-app-capable`, статус-бар `default`;
  - `viewport-fit=cover` и отступы `env(safe-area-inset-*)`, особенно для нижней панели;
  - `theme-color: #FFFFFF`.
- **Хостинг:** GitHub Pages через GitHub Actions (бесплатно, HTTPS). Учти `base` в Vite для пути репозитория. Деплой настраиваем на последнем этапе.
- **Тесты:** Vitest для логики расчётов.

## 3. Данные

```ts
type Flow = 'light' | 'medium' | 'heavy';           // скудные / средние / обильные

interface Period {                                  // одни месячные
  id: string;
  start: string;                                    // 'YYYY-MM-DD'
  end: string | null;                               // null = идут сейчас
}

interface Medication { name: string; dose?: string; time?: string; } // time 'HH:mm'

interface DayLog {                                  // дневник дня, все поля необязательные
  date: string;                                     // 'YYYY-MM-DD', ключ
  flow?: Flow;
  pain?: 1 | 2 | 3 | 4 | 5;
  pms?: 1 | 2 | 3 | 4 | 5;
  wellbeing?: 1 | 2 | 3 | 4 | 5;
  moods?: string[];                                 // множественный выбор
  meds?: Medication[];
  note?: string;
}

interface Settings {
  onboardingDone: boolean;
  lastExportAt: string | null;                      // ISO дата-время
  knownMedNames: string[];                          // для подсказок при вводе
}
```

- **Экспорт:** один JSON-файл `{ version: 1, exportedAt, periods, dayLogs, settings }`. Имя: `cycle-backup-YYYY-MM-DD.json`.
- **Импорт:** проверяет `version` и структуру. Перед заменой спрашивает подтверждение («Заменить текущие данные данными из файла?»).

## 4. Логика расчётов

Вынеси её в отдельный модуль чистых функций и покрой тестами.

**Базовые понятия**
- Длина цикла = дней от начала одних месячных до начала следующих.
- Цикл относится к году, в котором он начался (цикл 20 дек — 17 янв относится к году декабря).
- **Нетипичный цикл:** короче 21 дня или длиннее 45 дней. Чаще всего это случайная лишняя или пропущенная отметка. Нетипичные циклы хранятся и показываются в истории, но не участвуют ни в одном расчёте (средние, мин, макс, разброс).
- Пороги 21 и 45 вынеси в константы.

**Окно для прогноза**
- Средний цикл, минимальный и максимальный цикл для прогноза считаются по **последним 6 типичным завершённым циклам**, независимо от календарного года. Если циклов меньше 6 — по всем, что есть.
- Средние месячные для прогноза = среднее по последним 6 завершённым месячным.
- Округлять до целого.
- Пока типичных завершённых циклов нет: цикл 28 дней, месячные 5 дней, мин = макс = средний.
- Средний цикл на главной и в боковом меню — это среднее из окна прогноза.

**Статистика по годам** (только для экрана «История циклов»)
- Среднее, разброс и список циклов за выбранный год считаются по циклам, начавшимся в этом году, без нетипичных.
- Разброс = (макс − мин) / 2 по длинам циклов, округлённо, например «±1 день».

**Прогнозы** (только на один следующий цикл)
- Наиболее вероятное начало (V) = начало последних месячных + средний цикл.
- Самое раннее возможное начало = начало последних + минимальный цикл.
- Самое позднее возможное начало = начало последних + максимальный цикл.
- **Вероятные дни месячных** = V … V + средние месячные − 1.
- **Возможные дни месячных** = от самого раннего начала до (самое позднее начало + средние месячные − 1), кроме вероятных дней. Если все циклы окна одной длины, возможных дней нет.
- Прошедшие дни не закрашиваются ни как вероятные, ни как возможные.
- Если месячные идут сейчас (`end = null`): прогнозный конец = start + средние месячные − 1. Эти дни считаются вероятными.
- Овуляция = V − 14 дней.
- Фертильное окно = овуляция − 5 … овуляция + 1.
- Если какой-то день попадает и в возможные дни, и в фертильное окно, приоритет у фертильного окна.

**Текущее состояние**
- День цикла = сегодня − начало последних месячных + 1.
- «До месячных N дней» = V − сегодня. Первый вероятный день в календаре всегда совпадает с днём из карточки.
- Если V прошёл, а месячные не начались: показывать «Задержка N дн.» (N = сегодня − V). Будущие возможные дни при этом остаются в календаре.
- Во время месячных на карточке вместо «До месячных» показывать «Месячные, N-й день».

**Фазы**
- Менструальная: дни месячных.
- Фолликулярная: после месячных до начала фертильного окна.
- Овуляторная: фертильное окно.
- Лютеиновая: после фертильного окна до следующих месячных.

**Три способа отметить месячные — все через одну функцию `toggleDay(date)`** (после любой правки всё пересчитывается сразу)
1. Кнопка «Начались сегодня» / «Закончились сегодня» на индиго-карточке главной.
2. Режим «Изменить» в календаре главной: тап по дню ставит/снимает месячные.
3. Переключатель «Месячные сегодня» в дневнике дня.

Правила `toggleDay`:
- Отметить день вплотную к существующим месячным (соседний день) — продлевает их.
- Снять крайний день месячных — укорачивает месячные.
- Снять день в середине месячных — снимается только этот день, месячные делятся на две части.
- Отметить день далеко от любых месячных — начинает новые месячные из одного дня.
- Будущие дни отмечать нельзя.
- «Начались сегодня» = отметить сегодня (создаёт месячные `start = сегодня`, `end = null`); «Закончились сегодня» = поставить `end = сегодня`.

**Вне режима «Изменить» тап по дню календаря НЕ отмечает месячные — он открывает дневник этого дня.**

**Тесты обязательно покрывают:**
- нет данных;
- один цикл;
- разная длина циклов;
- задержка;
- месячные идут сейчас;
- переход через месяц и через год;
- февраль 28 и 29 дней;
- склейку и разделение месячных при тапах;
- все циклы окна одной длины → возможных дней нет, вероятных ровно столько, сколько средние месячные;
- первый вероятный день всегда равен дню из «До месячных N дней»;
- окно из 6 последних циклов: старый короткий цикл перестаёт влиять на диапазон после 6 новых;
- нетипичный цикл (например, 10 и 60 дней) не влияет на средние, мин, макс и разброс;
- январь: прогноз использует циклы прошлого года, а не откатывается к 28/5;
- цикл через Новый год относится к году начала;
- возможные дни и с ранней стороны (минимальный цикл), и с поздней (максимальный цикл);
- пересечение возможных дней с фертильным окном.

### 5.5 Боковое меню
Выезжает слева (ширина 310px, радиус справа 32px, фон затемнён).
- Заголовок «Меню», кнопка ✕.
- Две карточки: «Средний цикл 28 дн.» (индиго) и «Месячные 5 дн.» (коралл). Значения — из окна прогноза (раздел 4), те же, что на главной.
- **Пункты:**
  - **История циклов;**
  - **Экспорт в Файлы:** лаймовый пункт с подписью «Последний бэкап: [дата]». Экспорт через Web Share API с файлом (`navigator.canShare({ files })`), чтобы открылось меню «Поделиться» → «Сохранить в Файлы» / iCloud Drive / AirDrop на Mac. Если Web Share недоступен, файл скачивается;
  - **Импорт из файла:** `<input type="file" accept="application/json">`;
  - **Как считаются прогнозы.**
- Внизу мелко: «Данные хранятся только на этом iPhone. Прогноз фертильного окна — оценка, не для контрацепции.»

### 5.6 История циклов
- Кнопка «назад» и переключатель «[текущий год] / Архив». Архив — список прошлых лет, по тапу показывается тот же экран за выбранный год.
- Заголовок «История циклов».
- Три карточки за выбранный год (без нетипичных циклов): Цикл — среднее (индиго), Месячные — среднее (коралл), Разброс — ±N день (бирюза). Если типичных завершённых циклов в году нет — «—».
- Список циклов года (по году начала), новые сверху. В каждом: диапазон дат («31 авг — 27 сен»), справа длина («28 дней» или «идёт 17-й день»).
  - Ниже полоска: ширина пропорциональна длине цикла (максимум 35 дней = 100%, длиннее — тоже 100%), красная часть — месячные, сиреневая `#C9D0FA` — остальное.
  - Под полоской «Месячные 5 дней».
  - **Нетипичный цикл:** справа от длины серая пилюля «нетипичный», под полоской подпись `#6E6E80`: «Не учитывается в прогнозе. Проверь отметки в календаре.» Полоска того же вида, но с opacity .5.

### 5.7 Как считаются прогнозы
- Кнопка «назад», заголовок «Как считаются прогнозы».
- Подзаголовок «Прогнозы строятся по твоим последним 6 циклам. Чем больше циклов, тем точнее.»
- Шесть карточек `#F6F6F8` с цветной точкой того же цвета, что в календаре:
  - **Следующие месячные:** начало последних месячных + твой средний цикл. Этот день и следующие за ним дни месячных закрашены розовым;
  - **Возможные дни** (пунктирная точка): если циклы разной длины, месячные могут начаться раньше или позже. Эти дни обведены пунктиром — от самого короткого до самого длинного из последних циклов;
  - **Конец месячных:** день начала + твоя средняя длина месячных. Отметишь «Закончились» раньше или позже — пересчитается;
  - **Овуляция:** примерно за 14 дней до следующих месячных;
  - **Фертильное окно:** около 5 дней до овуляции и день после неё;
  - **Средние значения:** последние 6 циклов, включая отмеченные при первом запуске. Циклы короче 21 и длиннее 45 дней не учитываются — обычно это случайная отметка. Их видно в «Истории циклов».
- Лаймовая плашка «Это оценка»: «Прогнозы не подходят для контрацепции. Описания фаз — общая информация, не медицинский совет.»

## 10. Чек-лист приёмки
