# Спецификация: PWA-трекер менструального цикла

Личный PWA-трекер цикла для iPhone. Здесь всё, что согласовано: функции, логика расчётов, экраны, дизайн и техника. Документ живой: v1 собрана и работает, дальше по нему вносятся изменения. Если что-то в спецификации противоречит само себе или текущему коду — спроси меня, прежде чем решать самостоятельно.

---

## 0. Как работать с изменениями

1. Логику (раздел 4) меняй вместе с unit-тестами на Vitest. Я QA и проверяю граничные случаи. После изменения покажи отчёт тестов.
2. Проверять буду на iPhone: запускай `npm run dev -- --host` и пиши адрес по IP в локальной сети.
3. После каждого изменения коротко напиши, что сделано и что посмотреть, и сделай git-коммит с понятным сообщением.
4. Не добавляй ничего, чего нет в спецификации (аналитику, аккаунты, сервер, тёмную тему). Хочешь предложить улучшение — сначала спроси.

---

## 1. Что это и для кого

- Личный трекер для одного человека, только iPhone (Safari, установка на экран «Домой»).
- Язык интерфейса: русский. Все числа с существительными — с правильным склонением («1 день», «2 дня», «5 дней»).
- Тема только светлая.
- Без регистрации, без сервера, без платных сервисов. Данные хранятся только на устройстве.

---

## 2. Техника

- **Стек:** Vite + React + TypeScript.
- **PWA:** `vite-plugin-pwa`. Офлайн-работа, манифест, иконки, `display: standalone`.
- **Хранение:** IndexedDB через Dexie. При старте вызывай `navigator.storage.persist()`.
- **Даты:** date-fns с локалью `ru`. Все даты хранить как строки `YYYY-MM-DD` в локальном времени, без часовых поясов.
- **Шрифт:** Onest (через `@fontsource/onest`, веса 400–800), чтобы работал офлайн.
- **Под iOS:**
  - `apple-touch-icon`;
  - `apple-mobile-web-app-capable`, статус-бар `default`;
  - `viewport-fit=cover` и отступы `env(safe-area-inset-*)`, особенно для нижней панели;
  - `theme-color: #FFFFFF`.
- **Хостинг:** GitHub Pages через GitHub Actions, `base` в Vite = путь репозитория.
- **Тесты:** Vitest для логики из раздела 4.

## 3. Данные

```ts
type Flow = 'light' | 'medium' | 'heavy';           // скудные / средние / обильные

interface Period {                                  // одни месячные
  id: string;
  start: string;                                    // 'YYYY-MM-DD'
  end: string | null;                               // null = идут сейчас
}

interface Medication { name: string; dose?: string; time?: string; } // time 'HH:mm'

interface DayLog {                                  // дневник дня, все поля необязательные
  date: string;                                     // 'YYYY-MM-DD', ключ
  flow?: Flow;
  pain?: 1 | 2 | 3 | 4 | 5;
  pms?: 1 | 2 | 3 | 4 | 5;
  wellbeing?: 1 | 2 | 3 | 4 | 5;
  moods?: string[];                                 // множественный выбор
  meds?: Medication[];
  note?: string;
}

interface Settings {
  onboardingDone: boolean;
  lastExportAt: string | null;                      // ISO дата-время
  knownMedNames: string[];                          // для подсказки при вводе; последнее использованное — первым
}
```

- **Экспорт:** один JSON-файл `{ version: 1, exportedAt, periods, dayLogs, settings }`. Имя: `cycle-backup-YYYY-MM-DD.json`.
- **Импорт:** проверяет `version` и структуру. Перед заменой спрашивает подтверждение («Заменить текущие данные данными из файла?»).

## 4. Логика расчётов

Отдельный модуль чистых функций, покрытый тестами.

**Базовые понятия**
- Длина цикла = дней от начала одних месячных до начала следующих.
- Цикл относится к году, в котором он начался (цикл 20 дек — 17 янв относится к году декабря).
- **Нетипичный цикл:** короче 21 дня или длиннее 45 дней. Чаще всего это случайная лишняя или пропущенная отметка. Нетипичные циклы хранятся и показываются в истории, но не участвуют ни в одном расчёте (средние, мин, макс, разброс).
- **Случайная лишняя отметка:** завершённые месячные из одного дня (`start = end`), которые стоят ближе 21 дня к соседним месячным (до или после), не участвуют ни в одном расчёте: прогноз, «последние месячные», день цикла, фаза (в том числе для прошлых дней в дневнике и заметках), средние. Циклы вокруг неё считаются так, будто её нет (1 и 29 окт + лишний тап 11 окт → один цикл 28 дней).
  - Месячные, которые идут сейчас (`end = null`), учитываются всегда, даже если начались раньше 21 дня после прошлых.
  - В календаре такая отметка остаётся красной (это данные пользователя). В «Истории» — см. 5.6.
- Пороги 21 и 45 вынеси в константы.

**Окно для прогноза**
- Средний и минимальный цикл считаются по **последним 6 типичным завершённым циклам**, независимо от календарного года. Если циклов меньше 6 — по всем, что есть.
- Средние месячные = среднее по последним 6 завершённым месячным.
- Округлять до целого.
- Пока типичных завершённых циклов нет: цикл 28 дней, месячные 5 дней, мин = средний.
- Средний цикл и средние месячные на главной и в боковом меню — это значения из окна прогноза.

**Статистика по годам** (только для экрана «История циклов»)
- Среднее, разброс и список циклов за выбранный год считаются по циклам, начавшимся в этом году, без нетипичных.
- Разброс = (макс − мин) / 2 по длинам циклов, округлённо, например «±1 день».

**Прогнозы** (только на один следующий цикл)
- Наиболее вероятное начало (V) = начало последних месячных + средний цикл.
- Самое раннее возможное начало = начало последних + минимальный цикл.
- **Возможные дни** = от самого раннего начала до V − 1. Если все циклы окна одной длины, возможных дней нет.
- **Прогноз месячных** (вероятные дни) = V … V + средние месячные − 1. После этого ничего не рисуется: позднее начало не показываем.
- Прошедшие дни не закрашиваются ни как вероятные, ни как возможные.
- Если месячные идут сейчас (`end = null`): прогнозный конец = start + средние месячные − 1. Эти дни считаются вероятными.
- Овуляция = V − 14 дней.
- Фертильное окно = овуляция − 5 … овуляция + 1.
- Если день попадает и в возможные дни, и в фертильное окно, приоритет у фертильного окна.

**Текущее состояние**
- День цикла = сегодня − начало последних месячных + 1.
- «До месячных N дней» = V − сегодня. Первый вероятный день в календаре всегда совпадает с днём из карточки.
- Если V = сегодня: «Ожидаются сегодня».
- **Задержка:** V прошёл, а месячные не начались. N = сегодня − V.
  - Вместо названия фазы показывается «Задержка N дней», на карточке — «Задержка N дн.» (см. 5.2).
  - Фаза для карточек «Тело сейчас» и «Спорт сегодня» — лютеиновая.
  - Прогноз (вероятные и возможные дни) в календаре не рисуется — эти дни уже прошли.
- Во время месячных: «Месячные, N-й день».

**Фазы**
- Менструальная: дни месячных.
- Фолликулярная: после месячных до начала фертильного окна.
- Овуляторная: фертильное окно.
- Лютеиновая: после фертильного окна до следующих месячных.

**Отметка месячных — одна функция `toggleDay(date)`** для всех трёх мест (кнопка на карточке главной, режим «Изменить» в календаре, переключатель в дневнике). После правки всё пересчитывается сразу.
- Отметить день вплотную к существующим месячным (соседний день) — продлевает их.
- Снять крайний день месячных — укорачивает месячные.
- Снять день в середине месячных — снимается только этот день, месячные делятся на две части.
- Отметить день далеко от любых месячных — начинает новые месячные из одного дня.
- Будущие дни отмечать нельзя.
- «Начались сегодня» = отметить сегодня (`start = сегодня`, `end = null`); «Закончились сегодня» = поставить `end = сегодня`.

**Подсказка названия лекарства**
- `suggestMedName(input, knownMedNames): string | null` — одно название для подсказки или `null`.
  - Совпадение только по началу названия, без учёта регистра, пробелы по краям ввода игнорируются. С середины слова не ищем.
  - Работает с первой введённой буквы.
  - Несколько совпадений — первое в `knownMedNames` (последнее использованное).
  - Пустой ввод, нет совпадений или ввод уже полностью совпал с названием (без учёта регистра) — `null`.
- `rememberMedName(name, knownMedNames): string[]` — ставит название в начало списка. Если такое уже есть (без учёта регистра), переносит его в начало без дубля и сохраняет написание из нового ввода.
- `pruneMedNames(knownMedNames, dayLogs): string[]` — убирает из списка названия, которые больше не встречаются ни в одной записи дневника (без учёта регистра). Порядок остальных не меняется. Вызывается после сохранения дневника, чтобы опечатка, удалённая из записи, пропала из подсказок.

**Тесты обязательно покрывают:**
- нет данных; один цикл; разная длина циклов;
- задержка: «Задержка N дней», фаза для карточек лютеиновая, прогнозных дней нет;
- V = сегодня → «Ожидаются сегодня», первый вероятный день = сегодня;
- месячные идут сейчас;
- переход через месяц и через год; февраль 28 и 29 дней;
- склейку и разделение месячных при тапах;
- все циклы окна одной длины → возможных дней нет, вероятных ровно столько, сколько средние месячные;
- первый вероятный день всегда равен дню из «До месячных N дней»;
- окно из 6 последних циклов: старый короткий цикл перестаёт влиять на диапазон после 6 новых;
- нетипичный цикл (например, 10 и 60 дней) не влияет на средние, мин, макс и разброс;
- январь: прогноз использует циклы прошлого года, а не откатывается к 28/5;
- цикл через Новый год относится к году начала;
- возможные дни только до V (от минимального цикла); после V + средние месячные − 1 ничего не закрашено;
- пересечение возможных дней с фертильным окном;
- лишняя отметка последняя (месячные 1–5 окт, тап 12 окт) → прогноз и день цикла считаются от 1 окт;
- лишняя отметка внутри цикла (1 и 29 окт, тап 11 окт) → один цикл 28 дней, он остаётся в окне прогноза;
- фаза прошлого дня не считается от лишней отметки;
- месячные идут сейчас и начались через 15 дней после прошлых → учитываются;
- подсказка лекарства: «иб» → «Ибупрофен»; «ИБУ» → «Ибупрофен»; пустой ввод → `null`; новое название → `null`; «ибупрофен» при известном «Ибупрофен» → `null`; «Н» при [Нурофен, Но-шпа] → «Нурофен»; «Нурофен Ф» → `null`;
- `rememberMedName`: новое встаёт первым; «ибупрофен» при «Ибупрофен» в списке → в начало без дубля;
- `pruneMedNames`: название, удалённое из единственной записи, пропадает; название, которое есть в другой записи, остаётся; порядок сохраняется.

## 5. Экраны

### Навигация
- Плавающая нижняя панель-«таблетка» по центру снизу, над safe-area. Цвета одинаковые на всех экранах:
  - фон `#111114`, тень `0 10px 30px rgba(17,17,20,.24)`;
  - отступ между кнопками 22px, внутренние поля 8px 14px;
  - кнопки — круги 52px: «Главная», «+», «Заметки»;
  - **активная вкладка:** лайм `#DDF247`, иконка `#111114`, `aria-current="page"`;
  - **неактивная вкладка:** `#2E2E36`, обводка 1px `#4A4A55`, иконка `#C9C9D4`;
  - **«+»** — действие, а не вкладка: всегда белый `#FFFFFF` с чёрным плюсом. При тапе ~150 мс сжимается (`scale(.92)`) и становится `#E3E3E8`, затем снизу выезжает дневник за сегодня и закрывает панель;
  - на экранах из бокового меню (История циклов, Как считаются прогнозы) обе вкладки неактивные.
- Слева сверху на «Главной» и «Заметках» круглая кнопка ☰ (48px, фон `#F1F1F4`) открывает боковое меню.

  - **Обычный режим:** тап по дню (кроме будущих) открывает дневник этого дня и не меняет месячные.
  - **Режим «Изменить»:** серая кнопка-пилюля «Изменить» слева от стрелок месяца. По нажатию:
    - кнопка становится чёрной «Готово», стрелки месяца скрываются;
    - под заголовком месяца розовая плашка `#FFE0DC`: «Тапай по дням, чтобы отметить или снять месячные. Конец и прогноз пересчитаются сами.»;
    - прошедшие неотмеченные дни получают пунктирную коралловую обводку, будущие бледные (opacity .35) и не нажимаются. Прогнозные дни в этом режиме не показываются, чтобы не путать пунктиры;
    - тап по дню вызывает `toggleDay`;
    - «Готово» возвращает обычный режим.
- **Баннер бэкапа** (над календарём, лаймовый). Исчезает после любого экспорта в текущем месяце:
  - с 1-го числа каждого месяца, пока в этом месяце не было экспорта: «Сохрани бэкап за [прошлый месяц] →»;
  - 1–7 января вместо этого: «Сохрани архив за [прошлый год] →». С 8 января, если экспорта так и не было, — обычный текст «Сохрани бэкап за декабрь →». Данные прошлых лет не удаляются.

### 5.3 Дневник дня
Выезжающая снизу панель, радиус сверху 32px, «ручка» сверху, фон затемнён.
- Заголовок «Среда, 14 октября», под ним «17-й день · лютеиновая фаза». Справа кнопка ✕.
- **Всегда видны:**
  - **«Месячные сегодня»** — переключатель. Когда включён, появляются три кнопки интенсивности: Скудные / Средние / Обильные;
  - **«Боль»** — шкала из 5 кнопок, под ней подпись выбранного балла (раздел 7). Повторный тап снимает выбор;
  - **«Настроение и состояние»** — чипы с множественным выбором (раздел 7). Выбранный чип — бирюзовая заливка `#0E4A47`;
  - **«Лекарства»** — см. ниже.
- **По запросу:** серые чипы «+ ПМС», «+ Самочувствие», «+ Заметка» раскрывают свой блок. Заполненные блоки показываются сразу при открытии дня.
- Внизу чёрная кнопка «Сохранить», над ней отступ минимум 40px.
- **Сохранение:**
  - все правки дневника, включая переключатель «Месячные» (через `toggleDay`), применяются только по «Сохранить»;
  - ✕, свайп вниз или тап по затемнённому фону закрывают дневник без сохранения и без вопросов — правки теряются;
  - незаполненная форма лекарства (не нажата «Добавить») при «Сохранить» не сохраняется;
  - после сохранения вызывается `pruneMedNames`.

**Лекарства**
- Список записей: карточка `#DDE2FC`, радиус 20 — название, под ним «дозировка · время» (`#2E31A0`), кнопка удаления 44px. Под списком кнопка «+ Лекарство», она открывает форму.
- **Форма** — карточка `#F6F6F8`, радиус 22, поля 16px. Поля белые, высота 60px, радиус 16, обводка 1.5px `#E3E3E8`, в фокусе `#111114`:
  - «Название» на всю ширину;
  - «Дозировка» (плейсхолдер «400 мг») и «Время» (`<input type="time">`) в ряд, необязательные.
- **Плавающая подпись:** в пустом поле без фокуса «Название» стоит как плейсхолдер (17px, `#6E6E80`). При фокусе или вводе плавно (~180 мс) уезжает вверх и уменьшается до 13px. Подпись — настоящий `<label for>`.
- **Подсказка названия (призрачный текст),** логика — `suggestMedName`. Списка подсказок под полем нет.
  - Недостающая часть названия появляется серым `#8A8A9C` сразу после введённого текста: «Иб» + серое «упрофен». Хвост — декоративный слой под прозрачным `<input>` (`aria-hidden`), с тем же шрифтом и отступами; появляется с анимацией ~200 мс (сдвиг слева и проявление).
  - Справа внутри поля кнопка-пилюля «Вставить» с иконкой-галочкой: фон `#DDE2FC`, текст и иконка `#2E31A0`, высота 44px, `aria-label="Вставить Ибупрофен"`, появляется с лёгким увеличением ~200 мс.
  - Подсказка принимается **только тапом по «Вставить»**: название дописывается в написании из `knownMedNames`, хвост и кнопка исчезают, фокус и клавиатура остаются (обрабатывать на `pointerdown`/`mousedown` с `preventDefault`).
  - Enter в «Названии» ничего не дописывает, а переводит фокус в «Дозировку».
  - Нет совпадения, полное совпадение или текст перестал совпадать («Нурофен Ф») — нет ни хвоста, ни кнопки.
- **Кнопки формы:** в ряд, пилюли 48px. «Отмена» — `#E3E3E8`, тёмный текст: очищает и закрывает форму. «Добавить» — лайм `#DDF247`, текст `#1D2300`; без названия ничего не делает. После «Добавить» запись появляется в списке, форма очищается, название сохраняется через `rememberMedName`.

### 5.4 Заметки
Лента записей дневника. В неё попадают только дни, где в дневнике заполнено хотя бы одно поле. Дни, где месячные отмечены только в календаре, а дневник пустой, в ленту не попадают.
- Шапка как на главной, справа пилюля с годом. Заголовок «Заметки».
- Подпись «Показать записи» и фильтры-пилюли: Все / С болью / С лекарствами. Активный фильтр чёрный.
- Записи сгруппированы по месяцам, новые сверху. Подзаголовок месяца серый.
- **Карточка записи** (`#F6F6F8`, радиус 22):
  - сверху дата «14 окт, ср», справа серым «17-й день цикла». В дни месячных перед датой красная точка;
  - ниже строки «подпись — значение» (подпись серым, колонка 84px), только заполненные:
    - **Месячные:** Обильные;
    - **Боль:** 5 маленьких полосок, заполнено по баллу индиго, и текст «3 — заметная»;
    - **ПМС, Самочувствие:** так же, как боль;
    - **Состояние:** «Стресс, устала морально»;
    - **Лекарства:** «Ибупрофен 400 мг · 09:30»;
    - **Заметка:** текст.
- Тап по карточке открывает дневник того дня.

### 5.5 Боковое меню
Выезжает слева (ширина 310px, радиус справа 32px, фон затемнён).
- Заголовок «Меню», кнопка ✕.
- Две карточки: «Средний цикл 28 дн.» (индиго) и «Месячные 5 дн.» (коралл) — значения из окна прогноза.
- **Пункты:**
  - **История циклов;**
  - **Экспорт в Файлы:** лаймовый пункт с подписью «Последний бэкап: [дата]» или «Бэкапа ещё не было». Экспорт через Web Share API с файлом (`navigator.canShare({ files })`) → меню «Поделиться» → «Сохранить в Файлы» / iCloud Drive / AirDrop. Если Web Share недоступен, файл скачивается;
  - **Импорт из файла:** `<input type="file" accept="application/json">`;
  - **Как считаются прогнозы.**
- Внизу мелко: «Данные хранятся только на этом iPhone. Прогноз фертильного окна — оценка, не для контрацепции.»

### 5.6 История циклов
- Кнопка «назад» и переключатель «[текущий год] / Архив». Архив — список прошлых лет, по тапу тот же экран за выбранный год.
- Заголовок «История циклов».
- Три карточки за год (без нетипичных циклов): Цикл — среднее (индиго), Месячные — среднее (коралл), Разброс — ±N день (бирюза). Нет типичных завершённых циклов — «—».
- Список циклов года (по году начала), новые сверху. В каждом: диапазон дат («31 авг — 27 сен»), справа длина («28 дней» или «идёт 17-й день»).
  - Ниже полоска: ширина пропорциональна длине цикла (35 дней и больше = 100%), красная часть — месячные, сиреневая `#C9D0FA` — остальное. Под полоской «Месячные 5 дней».
  - **Нетипичный цикл:** справа от длины серая пилюля «нетипичный», под полоской подпись `#6E6E80`: «Не учитывается в прогнозе. Проверь отметки в календаре.» Полоска с opacity .5.
  - **Цикл с лишней отметкой:** обычная карточка с длиной без учёта отметки, без пилюли, под полоской подпись `#6E6E80`: «Отметка [дата] не учитывается. Проверь её в календаре.»

### 5.7 Как считаются прогнозы
- Кнопка «назад», заголовок «Как считаются прогнозы».
- Подзаголовок «Прогнозы строятся по твоим последним 6 циклам. Чем больше циклов, тем точнее.»
- Шесть карточек `#F6F6F8` с цветной точкой того же цвета, что в календаре:
  - **Следующие месячные:** начало последних месячных + твой средний цикл. Этот день и следующие за ним дни месячных закрашены розовым;
  - **Возможные дни** (пунктирная точка): если циклы разной длины, месячные могут начаться раньше прогноза. Эти дни обведены пунктиром — начиная с самого короткого из последних циклов;
  - **Конец месячных:** день начала + твоя средняя длина месячных. Отметишь «Закончились» раньше или позже — пересчитается;
  - **Овуляция:** примерно за 14 дней до следующих месячных;
  - **Фертильное окно:** около 5 дней до овуляции и день после неё;
  - **Средние значения:** последние 6 циклов, включая отмеченные при первом запуске. Циклы короче 21 и длиннее 45 дней не учитываются — обычно это случайная отметка. Их видно в «Истории циклов».
- Лаймовая плашка «Это оценка»: «Прогнозы не подходят для контрацепции. Описания фаз — общая информация, не медицинский совет.»

## 7. Шкалы и списки

Шкалы 1–5, где 5 — нужны сильные лекарства или врач:

| Балл | Боль | ПМС | Самочувствие |
| --- | --- | --- | --- |
| 1 | Почти не чувствую | Почти нет | Отлично, полна сил |
| 2 | Лёгкая, не мешает | Лёгкие проявления: вздутие, тяга к сладкому | Хорошо, лёгкая усталость |
| 3 | Заметная, мешает делам или тренировке | Заметно мешает: раздражительность, отёки, грудь | Так себе, тренировка через силу |
| 4 | Сильная, нужно обезболивающее | Сильно влияет на день и тренировки | Плохо, лучше отдых |
| 5 | Очень сильная: сильные лекарства или к врачу | Выбивает из жизни, стоит обсудить с врачом | Очень плохо: слабость, головокружение, температура — к врачу |

- **Цвета кнопок шкалы при выборе:** 1 `#E9ECFE`, 2 `#C9D0FA`, 3 `#8F94E6`, 4 `#4B4FD1`, 5 `#F2463A`. Выбранная кнопка с обводкой 2px `#111114`; у баллов 3–5 цифра белая.
- **Настроение и состояние** (множественный выбор): Спокойная, Норм, Грустная, Раздражённая, Тревожная, Стресс, Устала физически, Устала морально.
- **Интенсивность месячных:** Скудные / Средние / Обильные.

## 8. Дизайн-токены

- **Шрифт:** Onest. Заголовки 800 с letter-spacing −0.02…−0.03em, основной текст 500–600.
- **Цвета:**
  - фон `#FFFFFF`;
  - текст `#111114`; вторичный `#55556A`; подписи `#6E6E80`; призрачный текст подсказки `#8A8A9C`;
  - серые поверхности: кнопки `#F1F1F4`, карточки `#F6F6F8`; обводки `#E3E3E8`;
  - индиго `#4B4FD1`, на нём текст `#E3E4FF`;
  - бирюза `#0E4A47`, на ней текст `#D7EEEC`;
  - лайм `#DDF247`, на нём текст `#1D2300`;
  - коралл (месячные) `#F2463A`; вероятные дни `#FFE0DC`; возможные дни — пунктир 2px `#F2463A` без заливки;
  - светлый индиго `#DDE2FC` и `#C9D0FA`; на `#DDE2FC` текст `#2E31A0` (фертильное окно, карточки лекарств, «Вставить»);
  - нижняя панель: активная `#DDF247`; неактивная `#2E2E36`, обводка `#4A4A55`, иконка `#C9C9D4`; «+» `#FFFFFF`.
- **Радиусы:** большие карточки 26–28, карточки списков 20–22, поля ввода 16, пилюли и круги 999.
- **Отступы:** поля экрана 20px, между карточками 12px, между секциями 20–24px.
- **Доступность:**
  - тап-зоны не меньше 44px;
  - настоящие `<button>` и `<label>`;
  - `aria-label` у иконок-кнопок;
  - контраст текста не ниже 4.5:1. Исключение — призрачный хвост подсказки: он декоративный, а название дублируется в `aria-label` кнопки «Вставить».
- **Иконки:** обводочные SVG, stroke 2, скруглённые концы, без эмодзи.

- [ ] Работает в авиарежиме.
- [ ] Первый запуск: отметила два прошлых месяца, и прогноз сразу виден на главной.
- [ ] «Начались» → дни месячных и прогнозный конец; «Закончились» → прогноз пересчитан.
- [ ] Обычный тап по дню открывает дневник и не меняет месячные.

- [ ] В день V на карточке «Ожидаются сегодня».
- [ ] Задержка: заголовок «Задержка N дней», на карточке «Задержка N дн.», прогноза в календаре нет, карточки «Тело» и «Спорт» по лютеиновой фазе.
